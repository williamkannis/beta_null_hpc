# Diversity null modelling tools

Tools for estimating null model standardized diversity metrics using
parallel processing o both local machines and high performance computing
clusters. Based on workflow developed for:

[Null models reveal differing drivers of multidimensional beta diversity change in invaded metacommunities](BLANK)

[Invasion syndromes based on shared changes in multidimensional beta diversity](BLANK)

The archived version of this work flow can be found in version 1.0.0
